# BTL Vi Xử Lý - Vi Điều Khiển (CO3009)
**Đề tài:** Hệ thống đèn giao thông 2 tuyến đường trên mạch XNUCLEO-F103RB

## Hướng dẫn cài đặt và Build
1. Clone nhánh `dev` về máy cục bộ.
2. Mở STM32CubeIDE, chọn File > Import > General > Existing Projects into Workspace.
3. Chọn thư mục chứa repository.
4. Build project và đảm bảo mạch NUCLEO-F103RB đã được cấu hình Debug Serial Wire.
